# Steps needed to run locally

## 1. Clone the repository:  `git clone https://github.com/josephineeho/tip_calculator.git`

## 2. Open folder: `cd tip_calculator/`

## 3. Install deps: `npm install`

## 4. Start the server: `npm run dev`

## 5. Open link on browser: [http://localhost:5173/](http://localhost:5173/)
