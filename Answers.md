# Question 2

- I chosed react because this task had a lot of user interactions and react is good for building interactive user interfaces and also for live updates.
- I used flexbox over grid for layout because makes it very easy to place items where I want them and I am also familiar with it.
- I used tailwindcss over other css frameworks because it is very easy to use and it has a lot of utilities that i dont need to write them from scratch and also it is very customizable.
- I used useEffect hook from react to update states as input changes because it allows me to perform side effects in function components and it is also easy to use and understand.
- I used useState hook from react to manage states because it allows me to add state to function components and it is also easy to make it a dependency for useEffect hook to update states as input changes.
